# 新聞數字翻譯機

看到新聞寫「696.89 億元」，很難立刻知道這筆錢有多大。這個專案想把新聞裡的金額換成比較容易想像的尺度，例如幾個月薪水、幾碗滷肉飯，或工程預計完成時自己幾歲。

**目前是開發中的靜態網頁。** GitHub Pages 已建立，但首頁仍顯示「建置中」；換算、新聞卡片和測試都還沒實作。完整構想與驗收條件見 [規劃書](docs/規劃書.md)。規劃書中的新聞數字是發想時的例子，正式做成卡片前仍須逐則核對。

## 現在有什麼

- `index.html`：頁面入口，目前只有標題、規劃書連結與空的卡片區。
- `assets/css/style.css`：基本字型與間距，尚未完成手機版排版。
- `assets/js/app.js`：待實作的換算與渲染工作清單，**目前沒有可呼叫的換算函式**。
- `data/news.json`：一筆範例資料，來源連結與核對日期仍是空缺，**不能當成已核實的新聞資料**。
- `tests/test.html`：測試頁骨架，**目前沒有斷言或通過的測試**。

接下來要做的，是讓使用者輸入月薪、年齡與餐點單價，再把每則已核對的新聞數字換算成生活尺度。頁面預計提供原始來源、資料狀態與核對日期，也會說明「總經費除以人口」只是幫助理解的比喻，**不是每個人實際要繳的金額**。這些都是待完成項目，不是現有功能。

## 在本機查看

專案使用原生 HTML、CSS、JavaScript，無須安裝前端套件。因為頁面規劃用 `fetch` 讀取 `data/news.json`，請從專案根目錄開本機伺服器，不要直接以 `file://` 開啟：

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/` 可看到目前的建置中頁面；`http://localhost:8000/tests/test.html` 是尚未補上斷言的測試頁。**能開啟頁面不等於換算功能已完成或測試通過。**

## 資料與開發約定

新聞資料放在 `data/news.json`。正式加入卡片前，每筆資料都要有可開啟的原始報導或官方公告網址（`source`）及實際核對日期（`checkedAt`）；草案、已通過和預報不可混寫。不要貼整篇新聞內文。涉及全國人口的換算，須另外填人口數與內政部來源。

目前的範例資料還沒符合這些條件，因此不應拿它展示已核實的換算結果。實作順序與預計的資料欄位、公式、手機版及使用者測試標準，都記在 [規劃書](docs/規劃書.md)。

## 部署狀態

此 repo 的 GitHub Pages 已設定從 `main` 分支根目錄發佈，公開頁面是 `https://falltwo.github.io/news-number-translator/`。目前公開的仍是建置中頁面；更新 `main` 不會自動補上尚未寫好的功能。
