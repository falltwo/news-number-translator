# 新聞數字翻譯機

看到新聞寫「696.89 億元」，很難立刻知道這筆錢有多大。這個專案想把新聞裡的金額換成比較容易想像的尺度，例如幾個月薪水、幾碗滷肉飯，或工程預計完成時自己幾歲。

**目前是開發中的靜態網頁。** 前端介面、換算公式和公式測試已完成；還缺已核對的新聞資料，所以首頁目前沒有新聞卡片。完整構想與驗收條件見 [規劃書](docs/規劃書.md)。規劃書中的新聞數字是發想時的例子，正式做成卡片前仍須逐則核對。

## 現在有什麼

- `index.html`：首頁，含月薪／年齡／滷肉飯單價輸入、新聞卡片區與公式說明。
- `assets/css/style.css`：「報紙編輯台」風格的響應式版面，375px 手機寬度不會橫向捲動。設計說明見 [前端設計](docs/前端設計.md)。
- `assets/js/app.js`：讀取 `data/news.json`、四條換算公式、即時重算、複製卡片文字。只有 `source` 是 http(s) 網址且有 `checkedAt` 的資料才會顯示成卡片。
- `data/news.json`：一筆範例資料，來源連結與核對日期仍是空缺，**不能當成已核實的新聞資料**，所以目前首頁會顯示「已核對的新聞正在排隊」。
- `tests/test.html`：四條公式的測試，結果直接顯示在頁面上。

接下來要做的，是讓使用者輸入月薪、年齡與餐點單價，再把每則已核對的新聞數字換算成生活尺度。頁面預計提供原始來源、資料狀態與核對日期，也會說明「總經費除以人口」只是幫助理解的比喻，**不是每個人實際要繳的金額**。這些都是待完成項目，不是現有功能。

## 在本機查看

專案使用原生 HTML、CSS、JavaScript，無須安裝前端套件。因為頁面規劃用 `fetch` 讀取 `data/news.json`，請從專案根目錄開本機伺服器，不要直接以 `file://` 開啟：

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/` 可看到首頁；`http://localhost:8000/tests/test.html` 會顯示公式測試結果（分頁標題也會寫幾個通過）。

## 資料與開發約定

新聞資料放在 `data/news.json`。正式加入卡片前，每筆資料都要有可開啟的原始報導或官方公告網址（`source`）及實際核對日期（`checkedAt`）；草案、已通過和預報不可混寫。不要貼整篇新聞內文。涉及全國人口的換算，須另外填人口數與內政部來源。

前端讀資料時的規則：

- `amount`：沒填（例如颱風預報、沒有金額的政策）就只顯示標題、`note` 和來源，不做換算。
- `note`：選填，一兩句自己寫的說明，不要貼新聞原文。
- `status`：文字含「草案」顯示紅色、含「預報」顯示藍色、含「通過／核定／公布」顯示綠色，其他一律當草案。建議寫清楚是哪個機關，例如「行政院核定」。
- `population`、`populationSource`（內政部網址）、`populationAsOf`（人口統計月份）：`populationSource` 是 http(s) 網址時才會顯示「攤到每人」，並在公式區列出人口數和來源。
- 頁尾的「資料最後核對」取所有已顯示卡片中最新的 `checkedAt`。

目前的範例資料還沒符合這些條件，因此不應拿它展示已核實的換算結果。實作順序與預計的資料欄位、公式、手機版及使用者測試標準，都記在 [規劃書](docs/規劃書.md)。
